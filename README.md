# Орбита — менеджер студента

Один самодостаточный HTML-файл: без сервера, без внешних зависимостей, без сборки.
Работает из файла (двойной клик) и на любом HTTPS-хостинге.

## Как открыть
- **Локально:** открыть `orbita.html` в браузере (Chrome, Firefox, Edge, Safari).
- **На хостинге:** любая статическая HTTPS-ссылка (GitHub Pages, GitVerse Pages).

## Состав архива

## Быстрая проверка (5 минут)
Войти как **anna** → «Задания» → отправить работу → выйти → войти как **teacher** →
оценить 8/10 → войти как **dekanat** → обработать обращение → вернуться как **anna** →
увидеть результат. Сузить окно до 360px — мобильная вёрстка.
Включить «Холст» — карта всех дел со связями. Ctrl+K — поиск. «?» — шпаргалка клавиш.

Все данные вымышленные. Не официальный сервис МГИМО.
